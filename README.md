# Möwe Crewing

Möwe Crewing ist eine CiviCRM-Erweiterung für die Besatzungsplanung der
**Thor Heyerdahl**. Sie soll Veranstaltungen und Törns mit den benötigten
Bordrollen, Qualifikationen, Verfügbarkeiten und Besatzungszuweisungen verbinden.

## Status

Die Erweiterung befindet sich in einer frühen Alpha-Phase. Version `0.1.0`
stellt zunächst das technische Grundgerüst bereit. Es sind noch keine
fachlichen Crewing-Funktionen implementiert.

## Geplanter Funktionsumfang

- benötigte Bordrollen je Veranstaltung oder Törn verwalten
- Qualifikationen und deren Gültigkeit berücksichtigen
- Verfügbarkeiten und Interessen von Vereinsmitgliedern erfassen
- Personen einer Besatzung und konkreten Bordrollen zuordnen
- unbesetzte Rollen, Konflikte und fehlende Qualifikationen anzeigen
- Änderungen nachvollziehbar dokumentieren

## Entwicklungsumgebung

Die Erweiterung wird zunächst mit folgender Umgebung entwickelt und getestet:

- CiviCRM 6.17
- Drupal 10.6
- PHP 8.3
